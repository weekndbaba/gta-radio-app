Put your audio here (only audio you have the rights to).

  assets/audio/<Group_Name>/<Station_Name>.mp3

Each folder becomes a group card, each file becomes a station.
Underscores/hyphens in names are shown as spaces. Avoid real spaces in names.
Supported: mp3, m4a, aac, ogg, opus, wav, flac.
Files placed directly in assets/audio/ go into a group called "My Stations".
Delete the Example_Group folder (it only exists so the folder is not empty).
